Rumus Penting

Gunakan bagian ini untuk mengingat rumus dasar setiap materi.

Komposisi Fungsi

(f ∘ g)(x) = f(g(x))
(g ∘ f)(x) = g(f(x))

Urutan pengerjaan fungsi perlu diperhatikan karena komposisi fungsi pada umumnya tidak bersifat komutatif.

Fungsi Invers

  1. Misalkan y = f(x).
  2. Tukar posisi x dan y.
  3. Selesaikan persamaan untuk mendapatkan y.
  4. Ganti y dengan f⁻¹(x).
Jika f(x) = ax + b, maka f⁻¹(x) = (x − b) / a, dengan a ≠ 0.

Matriks

Penjumlahan: A + B = [aᵢⱼ + bᵢⱼ]
Perkalian skalar: kA = [kaᵢⱼ]

Dua matriks dapat dijumlahkan jika memiliki ordo yang sama.

Transformasi Geometri

  • Translasi: (x, y) → (x + a, y + b)
  • Refleksi terhadap sumbu-X: (x, y) → (x, −y)
  • Refleksi terhadap sumbu-Y: (x, y) → (−x, y)
  • Rotasi 90° berlawanan arah jarum jam: (x, y) → (−y, x)
  • Dilatasi berpusat di O dengan faktor k: (x, y) → (kx, ky)

Barisan dan Deret

Barisan aritmetika

Uₙ = a + (n − 1)b
Sₙ = n/2 (2a + (n − 1)b)

Barisan geometri

Uₙ = a × rⁿ⁻¹
Sₙ = a(rⁿ − 1)/(r − 1), untuk r ≠ 1
