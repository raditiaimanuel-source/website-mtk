Contoh Soal dan Pembahasan

Perhatikan langkah penyelesaian berikut.

1. Komposisi Fungsi

Diketahui f(x) = 2x + 1 dan g(x) = x − 3. Tentukan (f ∘ g)(x).

(f ∘ g)(x) = f(g(x))

= 2(x − 3) + 1

= 2x − 6 + 1

= 2x − 5

2. Fungsi Invers

Diketahui f(x) = 3x + 6. Tentukan inversnya.

Misalkan y = 3x + 6, lalu tukar x dan y: x = 3y + 6.

3y = x − 6, sehingga y = (x − 6)/3.

f⁻¹(x) = (x − 6)/3

3. Matriks

Diketahui A = [[1, 2], [3, 4]] dan B = [[2, 1], [0, 5]]. Tentukan A + B.

A + B = [[1+2, 2+1], [3+0, 4+5]]
A + B = [[3, 3], [3, 9]]

4. Transformasi Geometri

Titik P(2, 3) ditranslasikan oleh T(4, −1). Tentukan bayangannya.

P′ = (2 + 4, 3 − 1)

P′ = (6, 2)

5. Barisan dan Deret

Suatu barisan aritmetika memiliki suku pertama 3 dan beda 4. Tentukan suku ke-5.

Uₙ = a + (n − 1)b

U₅ = 3 + (5 − 1)4 = 3 + 16

U₅ = 19
